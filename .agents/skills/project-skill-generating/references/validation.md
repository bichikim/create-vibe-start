# Skill Validation

## Structure Checks

- Confirm the skill folder is under `.agents/skills/`.
- Confirm `SKILL.md` exists at the root of the skill folder.
- Confirm frontmatter includes `name` and `description`.
- Confirm every referenced file path resolves from the skill folder.

## Content Checks

- Check that `SKILL.md` is concise enough for first-read use.
- Check that longer guidance lives in reference files.
- Check that instructions are written as actions the agent should take.
- Check that examples match this repository's paths and conventions.

## Reporting

- Summarize the skill name and location.
- List reference files added or updated.
- Mention any validation command or file inspection completed.
